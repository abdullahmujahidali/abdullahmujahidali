## 🏗️ Selected Work

<sub>Client and employer work, so the code is private. Happy to walk through the architecture in a call.</sub>

**🩺 AI case-analysis platform for veterinarians**
Led the build of a platform that turns veterinary cases into structured reports. Knowledge ingestion and chunking, a Neo4j entity graph with an interactive explorer, LangGraph agent pipelines, Celery background processing and a report-generation flow — React/TypeScript front end on a Python back end.

**📅 Booking & marketplace platform**
Backend, web app and admin dashboard for a multi-vendor booking marketplace: payment-gateway checkout, real-time chat with invoices, multi-branch vendors, metrics exports, and a security hardening pass covering access control and sensitive-field exposure.

**📰 LLM article-analysis service**
An API that analyses news articles with LLMs on AWS Bedrock — retries for transient model errors, validation of structured JSON output, token refresh, and an integration for a social-media bot.
